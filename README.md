# NewsTok - Project I

NewsTok là một ứng dụng đọc tin tức ngắn với trải nghiệm cuộn dọc (vertical swipe) tương tự TikTok, giúp người dùng cập nhật thông tin nhanh chóng và trực quan.

## Mục tiêu dự án
- Cung cấp tin tức tóm tắt (3-4 dòng) kèm hình ảnh/video trực quan.
- Giao diện vuốt dọc mượt mà.
- Phát triển MVP (Minimum Viable Product) trong 8 tuần.

## Cấu trúc thư mục
- `/frontend`: Giao diện người dùng (Sẽ triển khai HTML/CSS/JS hoặc Flutter).
- `/backend`: API Server và xử lý logic bằng C++.

## Công nghệ sử dụng (Dự kiến)
- **Frontend:** HTML/CSS/JS (hoặc Flutter/React Native)
- **Backend:** C++ (Crow framework)
- **Database:** Json
